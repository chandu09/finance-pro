# Finance Pro 💰
A single-file personal finance tracker built for the Indian salary cycle.
Uses the **Avalanche method** to aggressively eliminate debt.

## Features
- 🔒 Safety Bar™ — controls flexible spending with one slider
- 🏔 Avalanche debt prioritization — highest interest rate first
- ⚡ Quick Kill alerts — flags loans you can close immediately
- 📊 Monthly surplus → prepayment recommendation
- 🎯 Sinking fund / savings goals tracker
- 🌙 Light & dark theme
- ⬇ Export to XLSX
- 💾 Auto-saves to browser localStorage — no account needed

## How to use
**Option 1 — Use online:**
👉 [Open Finance Pro](https://chandu09.github.io/finance-pro/index.html)

**Option 2 — Run locally:**
1. Download `index.html`
2. Open it in any browser
3. No installation needed

## Privacy
All your data stays in your browser. Nothing is sent to any server.
